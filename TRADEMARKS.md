# Orco name and logo

The code is licensed under Apache-2.0. The name "Orco" and the Orco logo are not: section 6 of
the license excludes trademarks.

You may:

- say your product works with, connects to, or is based on Orco;
- use the name to refer to this project in articles, talks and comparisons;
- run unmodified Orco internally under its own name.

Please ask first before you:

- ship a modified or forked version under the name "Orco" or a confusingly similar name;
- use the name or logo in a product, company, domain or app-store listing;
- suggest that the Orco project endorses you.

A fork is welcome. Give it a different name and say it is based on Orco.

Questions: open an issue at https://github.com/CJVigil/Orco.
